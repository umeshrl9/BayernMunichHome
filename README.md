# BayernMunichHome
Bayern Munich Homepage Design is a front-end project focused on designing a modern, responsive homepage layout dedicated to my favourite football club, FC Bayern Munich. The design is an original creation (not a replica of the official website) built entirely using HTML and vanilla CSS, reflecting the club's vibrant branding and dynamic spirit.
